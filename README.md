# Briefflow

Client brief intake + AI summary — an internal tool for a sales team to collect briefs,
get an AI-generated summary and priority, and manage them through a pipeline.

> **Planning docs (source of truth before the build):**
> - `docs/design.md` — architecture, data model, decisions, build plan
> - `docs/research.md` — web research findings and references
> - `docs/ai-usage-log.md` — AI usage log (required deliverable)

The full README (run instructions, env, architecture, trade-offs) is written during the
build and replaces this stub.
